# Ankuram – Student Management System (My First Project)

## Description
Ankuram is a basic Student Management System developed as my **first full-stack web project during school**.

This project helped me understand how different components of a web application work together:
- Frontend (JSP/HTML)
- Backend (Java Servlets)
- Database (MySQL)

---

## Objective
The purpose of this project was to:
- Learn the fundamentals of web development using Java
- Understand CRUD (Create, Read, Update, Delete) operations
- Practice database connectivity using JDBC
- Explore basic user login and authentication flow

---

## What You Can Learn From This Project
This project is useful for beginners who want to understand:

- Building a basic web application using Servlets and JSP
- Connecting Java applications with MySQL using JDBC
- Implementing CRUD operations
- Basic login system and data handling
- Data flow: User Interface → Backend → Database → Response

---

## ▶️ How to Run This Project
1. Clone or download the repository  
2. Open the project in Eclipse IDE  
3. Configure Apache Tomcat Server  
4. Create a MySQL database  
5. Update database credentials in the code  
6. Run the project on the server  

---

## Database
- Uses MySQL database  
- Stores application data  
- Connected using JDBC
